## Usage

The page component works best when combined with the [grid directives](./?path=/docs/helpers-directives-grid-guide--docs) which can be used to provide a responsive layout for the main content.

Import the page component and grid directives, then add them to your standalone component's `imports` array:

```ts
import {
  LgGridColDirective,
  LgGridContainerDirective,
  LgGridRowDirective,
  LgPageComponent,
} from '@legal-and-general/canopy';
```

and in your HTML:

```html
<lg-page>
  <div lgContainer>
    <div lgRow>
      <div lgCol="12">
        <h1>Your account</h1>
        <p>View and update your product details.</p>
      </div>
    </div>
  </div>
</lg-page>
```

## Variants

### Default

The default variant retains the standard page background. It is used when `variant` is omitted or set to `default`.

```html
<lg-page variant="default">
  <h1>Your account</h1>
</lg-page>
```

### Branded

Use `variant="branded"` for a page with the regal background. The header, footer and page layout are unchanged.

The page templates use blue mode with the bold theme for breadcrumbs on branded pages, and blue mode with the neutral theme on default pages. Set `lgColour="blue"` and bind `lgColourTheme` to the page variant when composing your own template; the page component does not apply breadcrumb themes automatically.

```html
<lg-page variant="branded">
  <h1>Your account</h1>
</lg-page>
```

## Dos and Don'ts

### Do

1. **Do** use the page variant to select the standard or branded background.
2. **Do** combine the page component with grid directives for responsive content.

### Don't

1. **Don't** use an inline background style to recreate the branded variant.

## Additional development details

### LgPageComponent inputs

| Input | Description | Type | Default | Required |
|-------|-------------|------|---------|----------|
| `variant` | Selects the page background: `default` or `branded` | `PageVariant` | `'default'` | No |

### LgPageComponent

Content projection slots

| Name        | Description                                                |
|-------------|------------------------------------------------------------|
| `lg-header` | Provides a slot for the standard header component          |
| `lg-footer` | Provides a slot for the standard footer component          |
| `<default>` | Any other components are projected into the central column |

It is possible to wrap the `lg-header` and `lg-footer` components and still use the page component.
You can do this by using the <a href="https://medium.com/ignite-ui/using-ng-content-ngprojectas-1664d7c1d3b" target="_blank">ngProjectAs</a> attribute.

```html
<lg-page>
  <app-header ngProjectAs="[lg-header]"></app-header>
  <router-outlet></router-outlet>
  <app-footer ngProjectAs="[lg-footer]"></app-footer>
</lg-page>
```
