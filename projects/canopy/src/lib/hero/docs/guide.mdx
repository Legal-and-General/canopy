# Hero

<span style={{ display: 'inline-flex', alignItems: 'baseline', gap: '0.25rem' }}><CustomBadge text="Updated" style={{ backgroundColor: '#caeedd', borderColor: '#caeedd' }} /><span class="small-text">for brand modernisation in Canopy{' '}<a href="https://github.com/Legal-and-General/canopy/releases/tag/v42.0.0" target="_blank" rel="noopener noreferrer">v42</a>.</span></span>

<p class="standfirst">A flexible pattern that is often used to display the most prominent information about a page. The module consists of lots of smaller presentation components that help to map out the common hero use cases.</p>

*Design guidance for this component is currently being rewritten. Please contact the Canopy team if you need more information on how to use this component.*

## Usage

Import the hero components in your application:

```js
import {
  LgHeroComponent,
  LgHeroCardComponent,
  LgHeroCardHeaderComponent,
  LgHeroCardTitleComponent,
  LgHeroContentComponent,
} from '@legal-and-general/canopy';
```

and in your HTML:

<Source of={HeroStories.ConversationalHero} />

Use `variant="child"` for a conversational UI hero.

### Other hero types and templates

You can extend the basic Hero component and create specific Hero layouts and implementations.

#### Hero with breadcrumbs

Using the `LgHeroCardHeaderComponent` together with `LgBreadcrumbComponent`, breadcrumbs can be easily added to the hero. See the [breadcrumb component](./?path=/docs/components-breadcrumb-guide--docs).

```html
<lg-hero>
  <lg-hero-header>
    <div lgContainer>
      <div lgRow>
        <div lgCol="12">
          <lg-breadcrumb variant="page" lgMarginBottom="none">
            <lg-breadcrumb-item>
              <a href="#"><lg-icon name="home-outline"></lg-icon>Home</a>
            </lg-breadcrumb-item>
            <lg-breadcrumb-item>
              Product Details
            </lg-breadcrumb-item>
          </lg-breadcrumb>
        </div>
      </div>
    </div>
  </lg-hero-header>
</lg-hero>
```

#### Product details

This component can used to display product data, for example on a product details page. Note the extensive use of presentation components to achieve the desired layout.

## Additional development details

### LgHeroComponent

This is the branded bar which runs across the top of the page.

#### Inputs

| Name      | Description                                      | Type                   | Default     | Required |
| --------- | ------------------------------------------------ | ---------------------- | ----------- | -------- |
| `variant` | Use `child` for a conversational UI. | `'default' \| 'child'` | `'default'` | No       |

### LgHeroContentComponent

This is the main section of the hero bar, it stretches the full width and is agnostic of grid system. You will need to configure the grid in the contents of this component to match your page layout.

#### Configure Grid

```html
<lg-hero>
  <lg-hero-content>
    <div lgContainer>
      <div lgRow>
        <div [lgCol]="12">
          <lg-hero-card> ... </lg-hero-card>
        </div>
      </div>
    </div>
  </lg-hero-content>
</lg-hero>
```

### LgHeroHeaderComponent

This is the top section of the hero bar, it stretches the full width and is agnostic of grid system. It is generally used to house the breadcrumb component if there is one. Similar to `LgHeroContentComponent`, you will need to configure the grid in the contents of this component to match your page layout.

### LgHeroCardComponent

A container component for displaying content within the hero area. The hero and hero card components are agnostic of the grid layout of the page. You will need to wrap the hero card component with the specific grid that is required.

### LgHeroCardHeaderComponent

This is the primary layout section of the hero component, it is used to contain the title, subtitle and principle value.

### LgHeroCardTitleComponent

This is where the main hero title should be provided. It should be located inside the hero header.

#### Inputs

| Name           | Description                                                      |   Type   | Default | Required |
| -------------- | ---------------------------------------------------------------- | :------: | :-----: | :------: |
| `headingLevel` | The level of the hero card heading: `1`, `2`, `3`, `4`, `5`, `6` | `number` |   n/a   |   Yes    |

### LgHeroCardSubtitleComponent

If the hero has a subtitle it should be located within this component. If a hero has a subtitle it is expected to also implicitly have a title. It should be located inside the hero header.

### Inline messages

Use `LgAlertComponent` with `status="info"` inside the hero card header to display product information, such as suspended payments. The [inline message component](./?path=/docs/components-inline-message-guide--docs) supplies the information icon automatically.

`LgHeroCardNotificationComponent` has been removed. Replace its selector with `lg-alert status="info"`, remove the manually supplied icon and replace its Angular import with `LgAlertComponent`.

### Principle data points

Use `LgDataPointComponent` with `variant="card-principle"` inside the hero card header. Provide its label with `LgDataPointLabelComponent` and its value with `LgDataPointValueComponent` using `size="lg"`. See the [data point component](./?path=/docs/components-data-point-guide--docs) for its inputs.

The hero-specific principle data-point wrapper, label and value components have been removed. Replace them with the shared components above and update their Angular imports.

### LgHeroCardContentComponent

This is the secondary layout section of the hero component, it is used to contain secondary information.

### Secondary data points

Use `LgDataPointGroupComponent` with `orientation="horizontal"` inside the hero card content, containing `LgDataPointComponent`, `LgDataPointLabelComponent` and `LgDataPointValueComponent` with `size="md"`. The group supplies list semantics when it contains multiple items.

Use `LgDataPointSecondaryLabelComponent` after the value for supporting text, such as "Received on 12 Mar 2019" beneath the tax code.

The hero-specific data-point list, wrapper, label and value components have been removed. Replace them with the shared components above and update their Angular imports.

### LgHeroCardFooterComponent

This where any extra text related to the hero card can be displayed, such as a small print.
