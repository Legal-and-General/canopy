# Accordion

<span style={{ display: 'inline-flex', alignItems: 'baseline', gap: '0.25rem' }}><CustomBadge text="Updated" style={{ backgroundColor: '#caeedd', borderColor: '#caeedd' }} /><span class="small-text">for brand modernisation in Canopy{' '}<a href="https://github.com/Legal-and-General/canopy/releases/tag/v44.0.0" target="_blank" rel="noopener noreferrer">v44</a>.</span></span>

<p class="standfirst">The accordion component reduces page clutter and cognitive load by letting users reveal sections of information as and when they need it.</p>

*Design guidance for this component is currently being rewritten. Please contact the Canopy team if you need more information on how to use this component.*

## Usage

Use the accordion component to hide sections of content to make pages easier to scan.

Information that is important or relevant to most users should not be hidden within this component and should be displayed on the page instead.

Accordions work best for simple content and links but can support rich content (sound, video, imagery, etc), if required.

If needed visually, an icon can be set for each accordion item heading. Use an `lg-icon` with a supported icon name. The header displays the chevron first, followed by the optional decorative icon and then the label. When a label wraps, both icons stay aligned with its first line.

Import the accordion components into your application:

```js
import { LgAccordionComponent } from '@legal-and-general/canopy';
```

and in your HTML:

```html
<lg-accordion [headingLevel]="2">
  <lg-accordion-item [isActive]="isActive" (opened)="handleItemOpened()" (closed)="handleItemClosed()">
    <lg-accordion-panel-heading>Item 1</lg-accordion-panel-heading>
    <p>Lorem ipsum dolor sit amet, consectetur adipiscing elit, sed do eiusmod
      tempor incididunt ut labore et dolore magna aliqua.</p>
  </lg-accordion-item>
  <lg-accordion-item>
    <lg-accordion-panel-heading>Item 2</lg-accordion-panel-heading>
    <p>Ut enim ad minim veniam, quis nostrud exercitation ullamco laboris nisi
      ut aliquip ex ea commodo consequat. Duis aute irure dolor in
      reprehenderit in voluptate velit esse cillum dolore eu fugiat nulla
      pariatur.</p>
    <button lg-button lgMarginTop="4" priority="primary">
      Test primary button
    </button>
  </lg-accordion-item>
  <lg-accordion-item (opened)="loadDynamicContent()">
    <lg-accordion-panel-heading>Item 3</lg-accordion-panel-heading>

    <ng-template lgAccordionItemContent>
      <app-dynamic-component [content]="dynamicContentItems$ | async">
          An example component that loads data from the network when this panel is opened.
      </app-dynamic-component>
    </ng-template>
  </lg-accordion-item>
  <lg-accordion-item>
    <lg-accordion-panel-heading><lg-icon name="news"></lg-icon>Item 4</lg-accordion-panel-heading>
    <p>An example of for an accordion panel heading with a decorative icon</p>
  </lg-accordion-item>
</lg-accordion>
```

## How it works

Accordions have a chevron to indicate that they are interactive. Clicking the heading toggle will expand or collapse the content within. By default, several accordion sections can be expanded at once. Set `[multi]="false"` on the group to allow only one open section at a time.

All items are closed by default. Set `[isActive]="true"` on an item to open it initially; the first item is not opened automatically.

Panels open and close immediately, without an expand or collapse animation. The chevron still rotates with an animated transition. Closed panels use `display: none`, so their controls cannot receive keyboard focus. Open panels have no animation wrapper clipping their content.

### Header actions

Place links or buttons in a container marked with `lgAccordionHeadingActions` inside the panel heading. These actions appear on the right, outside the toggle button, and do not expand or collapse the accordion. They can wrap beneath the heading when space is limited. Connect them to your application's destinations or action handlers; the links below use placeholder destinations.

```html
<lg-accordion-panel-heading>
  Item 1
  <div lgAccordionHeadingActions>
    <a lg-button priority="link" [backIcon]="true" href="#favourite">
      <lg-icon name="star-outline" />
      Favourite
    </a>
    <a lg-button priority="link" [backIcon]="true" href="#delete">
      <lg-icon name="trash" />
      Delete
    </a>
  </div>
</lg-accordion-panel-heading>
```

## Dos and Don'ts

### Do

![Accordion component - what you should do](docs/accordion/do.png)

1. **Do** use to hide secondary information from view.
2. **Do** make the label as short and descriptive as possible.

### Don't

![Accordion component - what you shouldn't do](docs/accordion/dont.png)

1. **Don't** use to hide key information.

## Additional development details

### LgAccordionComponent inputs

| Name           | Description                                                       | Type      | Default | Required |
|----------------|-------------------------------------------------------------------|-----------|---------|----------|
| `multi`        | Set false to only allow a single panel to be open at a time       | `boolean` | `true`  | No       |
| `headingLevel` | The level of the accordion headings: `1`, `2`, `3`, `4`, `5`, `6` | `number`  | n/a     | Yes      |

### LgAccordionItemComponent

#### Inputs

| Name       | Description                            | Type      | Default | Required |
|------------|----------------------------------------|-----------|---------|----------|
| `isActive` | The active state of the accordion item | `boolean` | `false` | No       |

#### Outputs

| Name     | Description                                     | Type                 | Default | Required |
|----------|-------------------------------------------------|----------------------|---------|----------|
| `opened` | Event emitted when the accordion item is opened | `EventEmitter<void>` | n/a     | No       |
| `closed` | Event emitted when the accordion item is closed | `EventEmitter<void>` | n/a     | No       |

### Lazy content initialisation

Wrap the panel content in an `ng-template` with the `lgAccordionItemContent` directive to initialise and render it only when the item is first opened. Once initialised, the content is retained when the item is closed and reopened.
