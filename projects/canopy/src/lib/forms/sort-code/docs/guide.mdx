# Sort code

<CustomBadge text="Pending" style={{ backgroundColor: '#005dba', borderColor: '#005dba', color: '#fff' }} /> <span class="small-text">Due for brand modernisation</span>

<p class="standfirst">Provides a directive to apply formatting and specific validators to the input component for entering a sort code.</p>

## Usage

Use the existing Reactive Forms controls for production forms. Signal Forms
controls are available as an opt-in, but Angular Signal Forms are experimental
in Angular 21 and their API may change. Consider the risks before using them in
production; see [Angular's guidance](https://v21.angular.dev/guide/forms/signals/overview).

For reactive forms, import the sort code and the [text input component](./?path=/docs/components-forms-text-input-guide--docs) into your application:

```js
  imports: [ ..., LgSortCodeDirective, LgInputComponent, LgHintComponent ],
```

and in your HTML:

<Source of={SortCodeStories.SortCode} />

Both the `lgInput` and `lgSortCode` directives have to be present on the input element.

The exact `lg-hint` should be copied as well to ensure the correct context is provided to the user.

### Validators

The sort code directive automatically adds the `required` and `pattern` validators by default.
The `pattern` validator checks that the sort code value has the following patterns: `000000`, `00 00 00` or `00-00-00`.

See the [form validation guide](./?path=/docs/components-forms-form-validation-guide--docs) for additional information.

### Format of the control value

On blur of the input we auto-format the value of the control to `00-00-00`.

### Signal Forms

Angular Signal Forms are experimental in Angular 21. Apply `lgSortCodeSchema`
to the field and use `LgSignalSortCodeDirective` with the signal input field:

```ts
import { apply, form } from '@angular/forms/signals';
import { lgSortCodeSchema } from '@legal-and-general/canopy';

readonly fields = form(this.model, path => {
  apply(path.sortCode, lgSortCodeSchema);
});
```

```html
<lg-signal-input-field [submitted]="submitted()">
  Sort code
  <lg-hint>Must be 6 digits long, for example 00-00-00</lg-hint>
  <input lgSignalInput lgSignalSortCode [formField]="fields.sortCode" />
</lg-signal-input-field>
```

Unlike the reactive directive, the signal directive cannot add rules to an
already-created signal form. The schema is required; the directive reports a
configuration error if it is missing. See the Signal Forms example for a
complete form with validation and submission.
